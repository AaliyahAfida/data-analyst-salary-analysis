# 📊 Data Analyst Salary Analysis (2020–2022)

An interactive data analysis project exploring salary trends for Data Analyst positions across different countries, experience levels, employment types, and work arrangements using Python and Tableau.

## 📌 Project Overview

This project analyzes the **Data Science Job Salaries (2020–2022)** dataset from Kaggle to understand global salary trends for Data Analyst roles.

The analysis focuses on identifying factors associated with salary differences, including experience level, employment type, remote work, company size, and company location.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Tableau Public
* Microsoft Excel

## 📂 Dataset

**Source:** Kaggle — Data Science Job Salaries (2020–2022)

The dataset contains salary information for data-related professions from multiple countries.

## 🔍 Analysis Performed

* Data cleaning and preprocessing.
* Salary distribution analysis.
* Salary comparison by experience level.
* Salary comparison by employment type.
* Salary comparison by remote work arrangement.
* Top countries by average Data Analyst salary.

## 💡 Key Insights

* Average salary generally increases with experience level.
* Full-time positions dominate the dataset.
* Remote roles offer competitive average salaries in this dataset.
* Salary varies significantly across company locations.
